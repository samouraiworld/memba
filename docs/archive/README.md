# Archive

Finished, dated records kept for reference. Nothing in this folder describes the current state of Memba: for that, read the documents one level up and the code. Archived files are not updated, except to keep their links working (one exception below).

- `professional-mainnet-2026-09/`: the text records of the September 2026 professional design review (audit, proposals, handoffs, decisions). Its screenshots (the `assets/` and `complete-review/` folders: 90 PNG images and the gallery's two files, about 14 MB) and the two scripts that built them (`scripts/design/build-review-pack.py`, `prepare-audit-assets.py`) were removed on 30 September 2026. The image links in these records no longer open, and the command in `COMPLETE-HANDOFF.md` that rebuilds the gallery no longer exists; the files are in the history of this repository up to commit `5102d46b`. One file of that pack, `ECOSYSTEM-SOURCES.md`, stays in `docs/design/professional-mainnet-2026-09/` because the ecosystem directory code cites it.
- `qa-2026-09/`: production QA evidence for the Memba OS apps, 27 and 28 September 2026, and the public beta guest sweep.
- `release-evidence-2026-09/`: release evidence for the mainnet A+B and C1 discovery releases.
- `features/`: finished game audits, designs and plans (Block Party, Space Invaders).
- `gno-core/`: upstream compatibility playbook and breaking-change board, written against chains that are now retired.
- `design/`: the App Store mainnet listing snapshot of 28 September 2026.
- Single files: `ROADMAP_PRE_V2.14.md` (roadmap before v2.14), `E2E_TEST.md` (manual test checklist from the test11 era).
